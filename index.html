Информация

Сайт предназначен для подготовки к аттестациям 1С. Основным функционалом является создание тестов из файлов .docx с вопросами.

Актуальность загруженных материалов

ПРОФ Платформа - вопросы от июля 2021г. (100% актуально на сентябрь 2025г.)

ПРОФ Управление торговлей - вопросы от февраля 2023г. (100% актуально на октябрь 2025г.)

СПЕЦ-КОНС Управление торговлей - билеты и конспекты (100% актуально на октябрь 2025г.)

Элементы управления на сайте

- Скачать с сервера. При наведении на значок (с ПК) выдвигается меню с вариантами теста, которые сохранены на сервере. Выбрав один из вариантов теста, следует нажать на эту кнопку. Произойдет автоматическая загрузка теста.

- Перемешать вопросы. Включает режим перемешивания вопросов. Для применения следует заново загрузить список вопросов - с сервера или из кэша.

- Сохранить в кэш. Сохраняет текущие вопросы в выбранную ячейку - из выдвижного меню с вариантами теста или в ячейку своего файла. Загрузив файл с сервера, следует сохранить его в кэш, нажав эту кнопку.

- Загрузить из кэша. Загружает вопросы из ячейки кэша. Используется для повторного создания теста - для первичного и повторного перемешивания или для смены теста, если он загружен в кэш.

- Очистить кэш. Очищает выбранную ячейку кэша.

- Сбросить ответы. Полностью очищает все расставленные ответы и сбрасывает статистику.

- Режим теста. Отбирает по одному вопросу из каждого раздела, как на аттестации. При повторном нажатии создается новый тест.

- Показать все ответы. Отмечает правильный ответ для каждого вопроса. Действие необратимо, для повторного решения необходим сброс теста.

!- Отметить вопрос. Добавляет вопрос в список помеченных вопросов, из которых позже можно создать свой документ и загрузить его на сайт для повторения. На вопрос из списка можно нажать и перейти к нему.

- Сформировать документ. Собирает все данные из списка ошибок и отмеченных вопросов и формирует .docx документ, который в дальнейшем можно загрузить на сайт и создать из него тест. Удобно для повторения спорных вопросов и своих ошибок.

Выпадающее меню позволяет отобразить вопросы из выбранной группы. Справа от него статистика по тесту - количество правильных, неправильных, оставшихся и помеченных вопросов, а также процент правильных ответов (отображается после хотя бы одной ошибки и правильного ответа).

Можно отвечать на вопрос с помощью цифр на клавиатуре, переключаться на предыдущий (Q) и следующий вопрос (E), а также добавлять в список отмеченных с помощью R.

Как загрузить свой тест

Если необходимо загрузить свой файл с тестом, то следует нажать кнопку "Выбрать .docx", а затем кнопку со стрелкой. Требования к файлу:

-файл .docx;

-вопросы представлены обычным текстом, не списком;

-ответы представлены нумерованным списком;

-если есть картинка, то она находится в абзаце текста вопроса;

-правильный ответ отмечен "|1";

- вариант ответа может ссылаться на другие варианты в виде перечисленных цифр. Для этого в конец варианта ответа нужно добавить multi-123, где 123 - другие варианты ответа. Так, перемешивание вариантов ответов будет работать корректно;

-multi должно идти после |1, если относится к правильному ответу.

-Можно сгруппировать вопросы по теме. Для этого перед первым вопросом новой темы должен быть абзац формата "ТЕМА [Номер]. [Название темы]"
